# Support

Distillate is Elastic-maintained with **no product SLA**. GitHub issues and pull requests are handled on a best-effort basis.

- **Engine bugs and questions** — open a GitHub issue in this repository.
- **Bugs in a Kibana, Cloud, or Adaptive UI feature** that happens to use Distillate — file them against that product. Distillate itself is not covered by Kibana Support or Cloud tickets.
- **Security** — report through [Elastic's security process](https://www.elastic.co/community/security). Do not file a public issue for a vulnerability.
- **Contributions** — see [`CONTRIBUTING.md`](CONTRIBUTING.md).
